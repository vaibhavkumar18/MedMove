# MedMove Backend API

The persistent data layer and optimizer integration bridge for the MedMove supply chain optimization platform. This backend provides a robust, tested, and secure foundation for managing hospital facilities, inventory, and network-wide optimization runs.

## 🚀 Quick Start

### 1. Prerequisites
- Python 3.11+ (Tested on 3.13)
- PostgreSQL 14+ (or SQLite for local testing)
- Git

### 2. Installation
Open your terminal and navigate to the `backend` directory:

```bash
cd backend

# Create and activate a virtual environment
python -m venv venv

# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
